# Security policy

This project is experimental and has no supported stable releases yet. For a vulnerability, use GitHub's **Report a vulnerability** / private security advisory feature in this repository. Do not post exploit details or credentials in public issues. If that feature is unavailable, open a public issue requesting a private reporting route without describing the vulnerability. We aim to acknowledge reports within seven days and coordinate disclosure after a fix and reporter review; this is a target, not a guarantee.

Reports should use only synthetic data. The CLI performs local static analysis and does not provide a runtime security boundary.
